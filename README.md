## Project Web Frontend TheFoodHub

## ✨ Features


- ម៉ឺនុយមានតាមប្រភេទ Pizza / Burger / Pasta / Drink
- កន្ត្រកកម្មង់ អាចកែចំនួន / លុប / មើល Invoice
- Form កក់តុ + Form ទំនាក់ទំនង
- Responsive ពេញលេញ គ្រប់ទំហំអេក្រង់

---

## 📁 Project Structure

```
Restaurant-TheFoodHub/
├── css/   
│   ├── style.css          → CSS + Responsive ទាំងអស់
├── html/
│   ├── about.html         → អំពីហាង / ក្រុមចុងភៅ
│   ├── contact.html       → ទំនាក់ទំនង + ផែនទី
│   ├── menu.html          → ម៉ឺនុយពេញលេញ
│   └── reservation.html   → កក់តុ
├── images/                → រូបភាពម្ហូប/ហាង
├── js/
│   ├── cart.js            → កន្ត្រកកម្មង់ (Add/Remove/Checkout)
│   ├── filter.js          → រើសមើលម៉ឺនុយតាមប្រភេទ
│   ├── script.js          → Navbar, Hamburger, Scroll-to-top
│   └── validation.js      → ត្រួតពិនិត្យ Form
├── index.html             → ទំព័រដើម
└── README.md
```
